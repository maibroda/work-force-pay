## What I checked and found sound

- **Tenant isolation.** Every new query carries `organizationId`; a token signed for one organization cannot reach a record in another (tested); another organization's administrator cannot open, verify, download or erase this one's requests (tested); suppression is per organization (tested).
- **Permissions in the data layer.** The new role matrix runs 27 operations as each of the 12 roles and fails if any role gets in without the permission, or is refused for another reason; I removed one check to prove the test catches it (it did: the roles without the permission were let in and the test named them). Only the company administrator (and super administrator) hold `sales.privacy.manage`.
- **Injection.** The only raw SQL in the new code is tagged templates with bound values; the search on the Privacy page uses the ORM; CSV exports neutralise formulas.
- **Uploads.** None: site survey photos are links, imports are text capped at 1,000 rows (a larger body is stopped by the server's own request limit).
- **Personal data in logs and the audit log.** The audit entries of every new action carry ids, kinds and counts, never a name, number or address (tested by scanning them).
- **Consent bypass.** The only code that sends a message to a contact is `sendEmailTo`; it asks the one yes/no that now also checks suppression. Every other email in the module goes to staff. A marketing WhatsApp is refused without the person's own link. An automation uses the same function. (F-03 is the one way round, by a person, and it is recorded.)
- **Idempotency.** The unsubscribe and the erasure can be repeated without a second effect (tested); retention erasure refuses a lead that is not past the period or was kept.
- **Payroll, statutory settings and contracts.** Nothing added in Phase 9 writes to payroll, statutory settings, contracts, rates or invoices. (F-01 is about a copy the handover already makes.)
- **Erasure itself.** The five guarded tables allow a change only inside the erasure step and only to personal columns; every other change, and the flag outliving its step, are refused (tested).

## What I did not test

- Behaviour behind a real proxy or on several servers (nothing is hosted).
- Anything in the browser beyond opening the unsubscribe page, the Privacy page and the list pages.
